# Social Pipeline

Social metadata is prepared for all B001 candidates, but actual verse text, bhavartha and voice-over remain blocked until canonical approval.

When a record is approved:
1. inject approved ಮೂಲ ಕನ್ನಡ
2. inject approved ಭಾವಾರ್ಥ
3. generate YouTube title/description/tags
4. generate Reel hook/on-screen text/caption/voiceover
5. export to CSV/JSON for production
