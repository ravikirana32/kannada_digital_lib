# Corpus Count Research

The project must not use a single number such as "2,100" as the definitive corpus count.

Current evidence:

- Uttangi's 1924 edition is reported by specialist scholarship as containing **1,928 poems**.
- The same scholarship says the collection was later expanded/revised in other editions.
- A secondary book description reports the revised second edition as growing to **2,100**.
- Kannada Wikisource is a separate digital transcription with its own numbering and section structure.
- The 1980 `Paramartha` critical edition is reported in secondary scholarship as containing **948 + 54** accepted poems and as comparing multiple versions.

These are not interchangeable counts.

## Project definition

The final project count will be:

> the number of unique, source-documented Sarvajna Tripadi records that pass the project's reconciliation and publication gates.

We will publish a corpus manifest explaining:
- which source editions were reconciled,
- which variants were merged,
- which additions were retained,
- which disputed/interpolated records were excluded,
- and why.
