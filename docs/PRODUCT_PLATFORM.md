# Sarvajna Product Platform

## Public Website
Searchable Kannada reader, source notes, variants, bhavartha, share links.

## Mobile
Expo/React Native app with the same canonical corpus.

## Admin
Editorial workflow for source intake, reconciliation, authenticity, rights, canonical approval, bhavartha and publication.

## Social
Approved canonical records export to YouTube and Instagram production metadata.

## API contract
Canonical record is the single source of truth. Website/mobile/admin/social should consume the same API rather than maintaining independent text copies.
