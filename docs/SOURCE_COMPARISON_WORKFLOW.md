# Source Comparison Workflow

1. Select candidate.
2. Load two or more source readings.
3. Preserve exact source text and locators.
4. Record differences; never silently normalize.
5. Choose comparison result:
   - same_text
   - minor_variant
   - major_variant
   - different_poem
   - needs_historical_check
6. Record canonical candidate only after evidence review.
7. Backend must enforce historical, authenticity, rights and editorial gates before publication.

The UI is a review aid; it is not authoritative evidence by itself.
