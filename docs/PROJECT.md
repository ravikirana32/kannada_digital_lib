# Project

## Vision
Preserve classical Kannada wisdom in trustworthy, searchable and reusable digital formats.

## Book 1
ಸರ್ವಜ್ಞ ಸಮಗ್ರ ತ್ರಿಪದಿಗಳು

## v1 scope
- Kannada only
- Original/source text
- Kannada bhavartha
- Life message
- Categories and keywords
- Source and rights metadata
- YouTube and Instagram metadata

## Architecture
Content is data-first. JSON is the canonical source. The same data feeds books, website, admin tools and social exports.
