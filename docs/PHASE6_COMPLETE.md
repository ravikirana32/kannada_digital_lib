# Phase 6 — Complete Corpus Acquisition & Reconciliation

## Goal

Scale the research from the pilot corpus to the complete Sarvagna candidate corpus without assuming that any one online collection is complete or canonical.

## Core workflow

Discover → acquire → preserve source text → fingerprint → cross-source match → deduplicate → register variants → assess authenticity → review rights → editorial approval → promote to canonical.

## Candidate capacity

The release provides 2,100 candidate slots because prior project research encountered sources/collections described with totals around this size. These slots are **placeholders only**. An empty candidate slot is not evidence that a verse exists.

## First operational batch

B001 = 1–75.

Existing scripts can report coverage and missing candidate slots. The actual text must be populated from source evidence.

## No fabricated corpus

This release does not manufacture 2,100 poems. It provides a controlled structure into which verified source records can be imported.

## Phase 6 completion definition

Engineering is complete when:
- acquisition schema works,
- batches work,
- source provenance is retained,
- variants are retained,
- canonical promotion is gated,
- progress/missing reports work.

Content completion is separate and requires actual source verification.
