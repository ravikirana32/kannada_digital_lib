# Style Guide v1.0

- UTF-8 Unicode.
- Preserve verified source wording exactly in `original`.
- Do not silently modernize source text.
- Editorial Kannada should be clear and natural.
- IDs use `SAR-0001`.
- Dates use `YYYY-MM-DD`.
- Source, bhavartha and social copy are separate fields.
- Unsupported historical claims must not be presented as fact.
