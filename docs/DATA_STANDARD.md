# Data Standard v1.0

One JSON document per Tripadi:

`data/sarvajna/tripadis/SAR-0001.json`

Required:
- id
- author
- work
- tripadi_number
- original
- bhavartha
- category
- keywords
- source
- rights
- review_status
- version

Lifecycle:
`draft → source_verified → editorial_review → approved → published`
