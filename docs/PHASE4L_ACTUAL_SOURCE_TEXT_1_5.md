# Phase 4L — Actual Source Text Collection 1–5

## Major result

The first five records now contain **actual source readings from multiple online traditions** rather than placeholders.

The comparison demonstrates that the sources do not share a universal numbering/order.

### Example

Current Wikisource begins its displayed `ಜಾತಿಸ್ಮರಣ ಪದ್ದತಿ` sequence with the Pushpadatta verse, while another online transcription begins with the Nandi/Ganesha invocation and then places the Pushpadatta verse second.

Therefore:

> Source number ≠ canonical number.

## Data policy

- Every reading is preserved.
- Each reading receives a source ID and locator.
- Normalized SHA-256 is used for reproducible matching.
- No reading is silently "corrected".
- No canonical text is selected yet.
- The historical 1924 edition and critical edition remain outstanding evidence.
