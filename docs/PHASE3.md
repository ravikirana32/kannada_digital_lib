# Phase 3 — Platform Engineering

## Goals
1. Production-oriented publishing foundation.
2. Web reader/search UI.
3. Admin/editor data model.
4. Social-content export model.
5. CI smoke tests.

## Non-goals
- No fabricated source text.
- No AI answer generation yet.
- No mobile app implementation yet.

## Completion criterion
A verified JSON entry can be validated, searched, rendered in the web UI, and transformed into publishing/social artifacts.
