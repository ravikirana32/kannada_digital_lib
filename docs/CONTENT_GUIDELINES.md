# Content Guidelines

1. Never fabricate a Sarvajna Tripadi.
2. Verify the exact source before adding source text.
3. Record page/section/locator where possible.
4. Record rights status.
5. Do not publish unverified source text.
6. Bhavartha is original explanatory writing, not a claim to be the author's own words.
7. Life message is modern editorial interpretation.
8. Social scripts must derive from approved content.
9. Record uncertain readings in notes rather than silently guessing.
