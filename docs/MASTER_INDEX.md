# Master Source Index

The master index is the control layer between research sources and canonical published Tripadi JSON.

## Current scope

- Research queue: Tripadis 1–75
- Reference source: SRC-001 (Internet Archive / Uttangi 1957)
- Candidate machine-readable reference: SRC-002 (Kannada Wikisource)
- No original verse text is copied into this index.
- No Tripadi is considered verified merely because it appears on a website.

## Why the index exists

Different editions/collections may:
- use different numbering,
- contain variants,
- group verses differently,
- omit/include different material,
- preserve different readings.

Therefore the final corpus count and canonical numbering will be established only after source comparison.
