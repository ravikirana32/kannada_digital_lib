# Pilot Verification Rules

1. Wikisource text may be used as a reference transcription.
2. It is not automatically the historically canonical reading.
3. SRC-001 must be cross-checked before final approval.
4. Rights remain `needs_review` until the project's redistribution basis is documented.
5. Corrections must be recorded; never silently overwrite a source reading.
6. No pilot record becomes `approved` until source, variant, rights and editorial gates pass.
