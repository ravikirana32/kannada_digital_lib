# Phase 5A — Canonical Sarvagna Corpus Foundation

## Goal

Move from research infrastructure to an evidence-gated canonical corpus.

## First batch

SAR-0001 through SAR-0005 are initialized from the Phase 4 source readings.

## Canonicalization rule

A source reading is not automatically canonical.

The approval chain is:

source evidence
→ historical/critical verification
→ variant assessment
→ authenticity assessment
→ rights verification
→ canonical text approval
→ bhavartha
→ publication/social outputs

## Important

Phase 5A does not claim that the first five are already canonical. It creates the controlled records needed to make those decisions safely.
