# Phase 4H — Edition-Aware Corpus Engine

Every source now has an edition identity. Source numbering is never assumed to be global.

Rules:
1. Preserve source-specific numbering.
2. Use fingerprints only to find match candidates.
3. Similarity does not prove authenticity.
4. Preserve meaningful variants.
5. Assign canonical numbering only after reconciliation.
6. Keep rights status separate from textual authority.
7. Do not copy modern commentary into canonical source text.

Pilot 1–5 remain unresolved pending exact 1924 and critical-source checks.
