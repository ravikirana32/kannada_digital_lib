# Phase 4 — Sarvajna Content & Verification

## Objective
Create a trustworthy content pipeline before scaling data collection.

## Source lifecycle
`discovered → rights_review → source_selected → transcription → source_verified → editorial_review → approved → published`

## Entry lifecycle
`draft → source_verified → editorial_review → approved → published`

## Source verification checklist
- Source title recorded
- Publisher/edition recorded where available
- Page/locator recorded
- Text checked against the source
- Variants recorded in notes
- Rights/redistribution status recorded
- Reviewer recorded
- Verification date recorded

## Editorial checklist
- Bhavartha is clearly editorial
- No unsupported historical claims
- No English translation in v1
- Category and keywords are appropriate
- Life message is clearly presented as modern interpretation
- Social copy derives from approved content

**Never invent, reconstruct or silently guess a Sarvajna Tripadi.**
