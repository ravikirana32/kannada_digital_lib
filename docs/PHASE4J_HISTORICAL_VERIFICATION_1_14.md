# Phase 4J — Historical Verification Batch 1–14

## Objective

The first 14 biographical/early-section records are being treated as a special research batch. They must be source-verified before the project assigns canonical numbering or publishes them as definitive Sarvajna text.

## Current evidence

The current Kannada Wikisource page has a `ಜಾತಿಸ್ಮರಣ ಪದ್ದತಿ` section. Its displayed first entries include the Pushpadatta/Vararuchi material, but the page also has a separate global numbering structure elsewhere. This confirms the need for section-aware and source-aware numbering.

A separate digital collection, Sarvajna Sanchaya, provides searchable poem text but is treated as a discovery/reference source rather than an automatic canonical source.

## Gates

For every record 1–14:

1. Exact source text located.
2. Edition and source number recorded.
3. Page/locator recorded.
4. Variant comparison completed.
5. Authenticity status assessed.
6. Rights basis documented.
7. Kannada bhavartha drafted only after source text is stable.
8. Editorial approval.

## Current state

Records 1–5 have a checked Wikisource reading but remain unresolved.
Records 6–14 are initialized as research records and must not be populated from memory.

## Rule

No record is `approved` merely because it appears on a current website. Textual authority, authenticity, and copyright status are separate decisions.
